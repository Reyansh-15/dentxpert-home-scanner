Hypothetical flow

Four layers to investigate.

A responsible program would test each layer independently, define failure modes, and prevent uncertain output from being presented as medical fact.

01 · Capture

Imaging research

Sensor and illumination approach unresolved.

02 · Process

Quality checks

Feasibility and reliability untested.

03 · Explain

Information design

Plain language without diagnosis or false reassurance.

04 · Protect

Privacy controls

Minimize data and make consent meaningful.

Design requirement

Uncertainty must travel with the output.

Any future interface would need to show limitations, distinguish image quality from health meaning, and direct users toward professional review when appropriate.

Data principle

Collect less by default

This website collects no personal or medical information. Any future research should start with the same data-minimization principle.

Human factor

Design for different abilities

Reach, vision, dexterity, language, and cognitive load belong in early testing—not as late additions.
